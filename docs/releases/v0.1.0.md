# Dicey Bar v0.1.0

Tagged `v0.1.0` at commit `b3bddab` on 2026-11-04 and published as a GitHub
pre-release on 2026-11-07. The first alpha baseline.

## Highlights

- A floating-island replacement for Omarchy's bar: themed left, center and
  right islands that keep Omarchy's theme integration and widgets.
- Monitor-scale-safe remapping after monitor layout or scale changes, without
  restarting the shell.
- Opt-in development copies (`scripts/dev.py`) kept separate from the installed
  production plugin.
- Upstream MIT notices, release tooling and marketplace preparation docs.
- Corrected plugin ownership and description metadata; the plugin ID stays
  `dicey.bar`.

## Notes

- Alpha software: `0.x` versions may change behavior between releases.
- Tested on Omarchy 4.0.6 / Quattro, Qt 6.12 and Quickshell 0.3.2.
- A premature 1.x tag was withdrawn and replaced by this release on
  2026-11-07; see [publishing](../publishing.md).
- `omarchy plugin update` follows the default branch, not tags; see
  [publishing](../publishing.md) for rollback to this tag.
